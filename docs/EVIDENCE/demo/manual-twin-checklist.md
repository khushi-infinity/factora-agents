- [ ] **No browser reload** at any point in this section.
- [ ] Press **Reset**: clock back to `2026-10-05 06:00:00`, CNC-03 amber again, distribution back

- [ ] `+10 min` and `+60 min` also work; `Reset View` returns the camera to the default angle.

## 6. Resilience

- [ ] Resize the window / a narrow viewport: layout does not break, canvas keeps the workspace.
- [ ] Hard-refresh on `/twin` (deep link works — SPA history fallback) and on `/`.
- [ ] **Fallback check:** in a browser or profile without WebGL, the page must show
      `Factory floor — table view` listing all 23 machines by line with state chips, plus the
      amber note "3D view unavailable…". The app must remain usable.
- [ ] Stop the backend and reload: `/twin` shows a red `Factory API unreachable` message rather
      than a blank page or a crash.

## 7. Non-negotiables

- [ ] No agents, no AI/LLM output, no "predicted failure" wording anywhere.
- [ ] No metric on screen that the backend does not return (no invented OEE).
- [ ] DevTools console: no errors, no 404s.
